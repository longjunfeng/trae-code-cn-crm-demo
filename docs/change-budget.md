# CRM 变更预算

## 本次示例任务

任务：增加“按角色筛选用户”能力，同时保留搜索、状态筛选、详情和停用行为。

## 预算

- 最多修改 8 个文件。
- 允许修改：`web/src/App.vue`、必要的 `server/src/index.ts`、`tests/crm.spec.ts`、测试报告和本次影响分析。
- 禁止修改：用户实体字段、角色权限语义、停用逻辑、Figma 设计令牌、发布配置和无关文档。
- 禁止顺手重构、统一命名、抽取组件或整理旧代码。

## 超预算规则

如果发现需要修改更多文件、触碰禁止区域或改变公共 API，必须停止编码并报告：

1. 超出预算的原因。
2. 新增文件和调用方。
3. 对权限、数据和兼容性的影响。
4. 是否可以拆成新的独立任务。

## 评审命令

```bash
git diff --stat
git diff --check
git status --short
```

评审者必须确认变更文件在白名单内，且没有仅为了美化代码产生的无关改动。
